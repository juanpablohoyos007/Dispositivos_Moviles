# Ejercicios Básicos en Dart: Análisis de ROI Móvil 🚀

Este es un repositorio de **trabajo estudiantil** donde aplicamos fundamentos de programación en Dart para resolver ecosistemas de negocio. 

## 📝 Descripción del Proyecto
El objetivo es analizar los sistemas operativos **Android e iOS**, tomando en cuenta factores críticos como:
* 📈 **Productividad:** Eficiencia en el desarrollo.
* 💰 **Economía:** Gasto promedio por usuario y recaudación global.
* 🛡️ **Seguridad:** Factores de confianza y prevención de fraude en las tiendas oficiales.

A través de código, concluimos cuál es la plataforma más rentable para iniciar un proyecto de startup con recursos limitados.
